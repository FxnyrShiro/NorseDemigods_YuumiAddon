# YuumiAddon

A BepInEx plugin that adds the Yuumi god from League of Legends to the NorseDemigods mod.

## Features

- Adds Yuumi as a new demigod with all her abilities
- Q Ability: Prowling Projectile
- W Ability: You and Me
- E Ability: Zoomies
- R Ability: Final Chapter

## Requirements

- BepInEx 5.4.2360
- NorseDemigods 1.9.3
- Jotunn 2.30.2

## Installation

1. Install BepInEx
2. Install NorseDemigods mod
3. Install Jotunn
4. Place YuumiAddon.dll in your BepInEx/plugins folder
5. Place Icons/yuumi_icon.png in your BepInEx/plugins/YuumiAddon folder

## Configuration

The mod uses the config system of NorseDemigods. Configuration can be found in:
- `BepInEx/config/NorseDemigods.cfg`
- `BepInEx/config/YuumiAddon.cfg`

## Compatibility

This plugin is designed to work with the latest version of NorseDemigods and is compatible with other mods that don't conflict with the NorseDemigods framework.
